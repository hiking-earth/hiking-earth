# 统一账号网关源码边界

`business/` 是统一账号 HTTP 和微信云网关的正式业务源码，必须随 `client-api` 一起提交、打包和部署。它不是可以删除后从独立函数自动重建的缓存。

独立 `cloudfunctions/<name>/index.js` 用于其各自入口；两种入口的身份来源和可用上下文不同。例如独立 `social-manage` 已停止提供旧账号服务，不能复制来覆盖这里的社交实现。涉及两个入口的业务变动需要分别维护，禁止盲目批量复制。

部署前仍调用 `python3 app/scripts/compose-client-api.py`。保留旧命令名称以兼容部署工具，但它现在检查路由清单、统一身份边界和包内相对依赖，再准备路线目录快照；不生成或替换业务实现。

验收会话可先运行 `python3 app/scripts/compose-client-api.py --check-only` 只检查源码边界，不准备快照、不调用云端。缺少任一处理器或辅助文件会明确停止，避免丢失 `owner-admin.js`、`route-access-audit.js`、淘宝/京东候选适配器等依赖。

`scripts/deploy-client-functions.py` 在远端更新前冻结本地发送源码、备份已有函数；发送后逐文件回读核对，失败时尝试恢复已有函数。它不会配置管理员身份或模型/电商密钥，也不代表业务验收通过。所有者权限、凭据及实际云环境保持独立操作边界。

本轮只修改部署准备源码，尚未执行该命令或部署；由另一会话检查依赖缺失、处理器保留、快照生成以及远端回读流程。
