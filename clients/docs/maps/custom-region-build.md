# 按位置生成离线地区包

工作流 `offline-map-build.yml` 的手动运行支持 `custom_latitude`、`custom_longitude`、`custom_radius_km`、`custom_name`。经纬度均留空时继续构建预置目录；仅填写一个坐标会校验失败。

自定义区域半径为 1–10 公里，跨日期变更线自动拆分，高纬区域按生成器支持的大小分块。Mercator 极区不覆盖，越界请求明确拒绝。

所有分块使用同一上游快照，逐包校验、记录大小、SHA 和许可。完整批次导出 `catalog.json`；失败批次保留检查点和日志。工作流诊断产物保留 14 天；成功的自定义区域批次还会打包成 ZIP 并发布为独立的 GitHub Release 下载资产。该下载资产可公开访问，但会随对应 Release 保留，除非维护者删除 Release 或资产；它不等同于网站托管或客户端内的地图目录。自定义区域不会提交到应用内置目录，避免每次请求增加安装包体积。

当前边界：此入口由有仓库 Actions 权限的维护者手动运行；普通用户不能在客户端自行提交坐标或请求生成。已生成包可通过对应 GitHub Release 公开下载，但客户端没有 Release 目录/下载入口，网站也没有地图搜索与自助请求流程。工作流尚未完成真实运行与下载验收。底图不提供高程、路线开放核验或完整导航。

自定义批次另导出 `distribution/`：其中 `catalog.json` 使用客户端既有目录格式，`source-inventory.json` 保存生成来源，包文件复制后再次验证 SHA。工作流当前将该目录打包后上传到独立 GitHub Release；若以后接入客户端同源目录，仍需将文件挂载到所选下载根的 `static/offline-maps/` 并提供 HTTPS。导出器拒绝覆盖既有目录，损坏来源不创建分发目录；复制失败不留下可发布目录标记。Release 包尚未与客户端主目录或网页地图目录合并，也未做真实下载和端上验收。
