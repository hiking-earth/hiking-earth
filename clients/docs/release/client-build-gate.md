# H5 与微信小程序候选构建门禁

`.github/workflows/client-build.yml` 为 H5 和微信小程序生成候选包，执行类型检查与照片选择生命周期用例，并检查构建目录小于 500,000,000 字节。

为遵守“功能完成后统一验收”，整个构建任务仅在仓库变量 `CLIENT_BUILD_READY` 精确等于 `true` 时运行。变量未设置或为其他值时，即使工作流被默认分支变更触发、手动启动或作为可复用工作流调用，也会跳过构建任务。

只有在客户端源码功能冻结并合入默认分支后，才设置此变量并启动统一构建与检测。当前 PR 不设置变量、不触发工作流；源码存在不代表包体已构建或已通过门禁。
