# 手机号登录的免费方案边界

核对日期：2026-10-07

- 项目所有者此前确认以个人身份运营，并要求优先免费、不启用付费服务。
- 微信小程序官方手机号授权需要用户主动点击授权按钮；官方文档指出此能力面向完成认证的非个人主体。小程序主体是否具备资格，最终以微信公众平台实际权限为准：<https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html>
- CloudBase 现行价格表中，个人版“小程序手机号登录”标记为不支持，标准版及以上支持；同一文档把套餐价格列为个人版19.9元/月、标准版199元/月。不得为实现该能力擅自升级：<https://cloud.tencent.com/document/product/876/75213>
- CloudBase 短信验证码登录文档称仅有首月100条免费额度，超过后需要购买短信资源包；现行价格表列出短信资源包1000条50元，且短信提交成功即计费：<https://cloud.tencent.com/document/product/876/48796> <https://cloud.tencent.com/document/product/876/75213>
- 因此，在现有个人主体和零付费约束下，不能启用可靠的手机号验证码登录，也不能用本机号码、测试号码或客户端自报号码假装完成验证。当前可用的跨端方式仍是微信小程序扫码确认；账号密码注册登录也仍在客户端提供。
- 账号数据以服务端已验证的微信身份为归属。即使将来接入手机号，也必须由服务器验证号码，再创建或关联唯一的手机号映射；如果该号码已指向另一个含数据的账号，需安全迁移或用户确认，不能根据客户端填写的相同号码静默合并。

后续仅在所有独立功能完成、集中处理所有者事项时确认：保持免费并继续使用微信扫码/账号密码，还是由所有者改变主体或明确承担官方手机号/SMS能力的费用。不得自行打开付费能力。
