## 仍被外部条件阻断

| 模块 | 阻断原因 | 正式完成条件 |
|---|---|---|
| 全部路线开放状态 | 仍有候选路线缺属地官方核验 | 每条路线有官方来源、时间和复核人 |
| 正式天气服务 | SmartWeatherAPI 凭据未配置 | 申请、配置、限频和失败策略完成 |
| 路线轨迹/长度/爬升 | 部分为演示测绘或认知示意 | 逐条取得来源和许可 |
| 图片发布 | 当前仍有 Unsplash 演示影像 | 逐张完成自有/授权/开放许可记录 |
| 全球户外新闻和景点动态 | 目前只有数据结构和占位内容 | 接入合规官方来源或明确保持待接入 |
| 账号和多端同步 | 当前是无登录本地存储 | 完成认证、数据库、隐私、删除和导出 |
