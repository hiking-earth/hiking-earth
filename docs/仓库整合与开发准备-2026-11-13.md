## 自动化

根目录 .github/workflows/ci.yml 继续检查网站；clients.yml 检查共享客户端类型、定位/照片回归、H5 和微信编译。
原客户端工作流完整保存于 clients/.github/workflows/ 作为迁移资料，不会在嵌套目录自动执行。涉及发布、密钥、离线资源刷新和定时网络任务的旧工作流尚未迁入根目录启用，既有仓库中的服务与发行版链接保持原地址。

## 本机迭代

使用 Node 22；npm run setup 安装全部 Node 依赖。npm run dev、dev:client、dev:desktop 分别启动网站、共享客户端和桌面开发。

npm run build:desktop 只生成当前架构的 .app，固定输出 clients/desktop/src-tauri/target/release/bundle/macos/徒步地球.app。不要复制新的软件本体到其他文件夹。

构建发现并修复了导入源码的条件编译变量重名、地区照片可选字段类型、识别响应 provider 可选类型，以及地图过滤表达式写法。公告缓存按原有 90 天规则重新校验，撤下 6 条过期记录，保留 219 条；这不是重新联网采集公告。同步修复了缓存复核状态与目录发布校验不一致的问题。

稳定发布清单仍为 ready=false。账号、跨设备同步、系统定位授权、真实轨迹和更新没有在此次代码整合中完成真机验收。
