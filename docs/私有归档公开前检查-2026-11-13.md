检查目标：hiking-earth/hiking-earth-build-archives 的 main 历史和 archive-20261030 的四个附件。未经检查的原始归档没有上传到公开仓库。

## 结果

- Git 历史仅有 1 次提交和 README.md。Gitleaks 8.30.1 全历史扫描未发现凭据。
- 四个 64 MiB 分卷均通过与 GitHub 远端资产摘要的 SHA-256 比对。
- 拼接后的 gzip/tar 截断，最后可识别成员为 libtauri 编译库，无法完整读取。摘要一致只能证明下载与远端一致，不能证明远端归档完整。
- 对可读取的约 541 MiB 内容、2346 个文件条目执行字符串扫描，其中 2345 个文件可完整读取，最后 1 个只扫描到可读部分。
- Gitleaks 命中 2 处 generic-api-key；分别对应 muda 0.20.0 的 accelerator 文档与 ring 0.17.14 的 RSA 文档，候选文本均与本地公开依赖源码一致，判定为依赖文档误报。
- 额外匹配 GitHub token、AWS Access Key、腾讯 SecretId、OpenAI key 和私钥 PEM 标头，未发现命中。
- 471 个文件含 macOS 本机用户路径，2 个文件含 Linux 用户路径；这些编译缓存会暴露机器目录信息，不适合直接作为公开附件。

## 处理

仅合并已检查的 Git 源码历史与说明，所有者随后明确要求删除有隐私的内容，已删除原私有 archive-20261030 Release 及其四个附件；不发布到公开 Release。本机下载副本和原始字符串扫描临时文件也已删除，保留不含凭据原文的检查记录。当前本地只使用从统一源码重新生成的软件本体。

此结论是“已扫描的可读内容未发现真实凭据”，不能保证缺失/不可读内容没有秘密，也不验证任何凭据是否仍有效。报告不记录候选密钥原文、本机用户名或完整个人路径。原始扫描临时文件只放在本机 .git 内，禁止提交。
