# 你的第一个模块：嵩山路线档案

目标：亲手把“嵩山经典步道”补成一条有个人判断的路线档案。完成后，网页会自动展示你写的内容。

## 只改一个文件

打开 `data/routes.ts`，搜索：

```ts
// ===== 这是你的第一个编程练习
```

你只需要把下面四段文字替换成自己的内容：

```ts
highlights: [
  "待你填写：这条路线最吸引人的一个亮点",
  "待你填写：最适合拍照或休息的特点",
  "待你填写：你认为它值得去的理由",
],
riskNotice: "待你填写：请用一句话说明新手最需要注意的风险或准备。",
```

## 写作要求

- 每条亮点控制在 8 到 18 个字，写具体，不要只写“很好看”。
- 风险提示只写你能确认的常识性准备，例如天气、补水、体能、登山鞋；不确定的开放信息不要猜。
- 不要改英文符号、方括号、引号、逗号和冒号，只替换中文文字。

## 你可以这样写

```ts
highlights: ["中岳主峰视野开阔", "山脊步道适合秋日远眺", "郑州出发当天可往返"],
riskNotice: "山路起伏明显，建议穿防滑登山鞋并预留充足饮水。",
```
