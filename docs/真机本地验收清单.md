# 徒步地球真机本地验收清单

适用版本：v022 之后的本地参赛版。所有测试只访问本机或同一可信局域网，不发布、不上架。

## 连接方式

1. 在 Mac 终端进入 `网站源码`，运行 `npm run dev`。
2. Mac 本机使用 `http://localhost:8080/`。
3. 手机和 Mac 处于同一 Wi-Fi 时，使用终端显示的 `http://<Mac局域网IP>:8080/`。
4. 本次网络已验证 Mac 地址为 `http://192.168.0.20:8080/`；网络切换后 IP 会改变，应以终端输出为准。

## 证据边界

- 浏览器开发者工具的 iPhone/Android 尺寸模拟只能作为网页回归证据，不能替代真实设备验收。
- 只有在真实 iPhone、Android 手机和 Windows 电脑上完成触摸/返回键/网络切换/持续操作，并记录设备、系统、浏览器和截图后，才能勾选对应真机项目。
- 当前 v022 已验证 Mac 本机和同一局域网地址均返回 HTTP 200；真实设备项目仍保持未勾选。

## iPhone Safari

- [ ] 首页先出现完整 3D 地球、星空背景和路线锚点；无登录要求。
- [ ] 单指拖动可旋转地球，双指缩放流畅；缩放、旋转连续 30 秒无明显掉帧或白块。
- [ ] 关闭路线列表后，地球可见区域足够大；底部功能栏不被 Home 指示条遮挡。
- [ ] 打开路线列表，按“开放中”“秋季”“轻装”“住宿”等组合筛选，路线数量和锚点同步变化。
- [ ] 点击太室山等路线后，镜头平滑飞入；详情中显示区域边界、路线线条和周围压暗效果。
- [ ] 打开装备助手，改变出发日期和轻装/中度/重装，清单与风险提醒应变化。
- [ ] 打开“推荐”“社区”“足迹”功能中心，确认文本输入时 Safari 不会自动把页面放大。
- [ ] 旋转地球或关闭/打开功能中心后，内存不持续攀升、页面不会重载或闪退。

## Android Chrome

- [ ] 重复 iPhone 的地球、筛选、飞入和功能中心验收。
- [ ] 检查返回键：关闭弹层优先于退出页面。
- [ ] 检查状态栏、底部手势区和中文字体是否被裁切。
- [ ] 检查低电量模式或中低端机：地图仍可操作；允许降低细节，但不能出现黑屏、白屏或无法拖动。

## Windows Chrome/Edge

- [ ] 1366×768 和 1920×1080 下，右侧筛选栏、左侧路线详情、地图控件不互相覆盖。
- [ ] 鼠标滚轮缩放、拖拽旋转、城市 3D 开关、地名道路开关均可用。
- [ ] 调整浏览器窗口尺寸后，地图自动填满容器且锚点可点击。
- [ ] 连续切换 5 条路线，确认没有明显内存持续增长、重复锚点或历史路线线条残留。

## 结果记录

记录问题时请写明：设备型号、系统版本、浏览器版本、访问地址、出现步骤、截图或录屏。若出现地图空白，先记录地址栏地址与网络状态，不要清除浏览器数据。

## 发布前数据合规验收

- [ ] 每条可发布路线都有属地官方开放状态来源、核验日期和复核人。
- [ ] 天气展示来自已申请并配置的中国气象局官方接口；接口失败时页面明确显示不可用，不显示旧数据冒充实时数据。
- [ ] 路线长度、爬升、轨迹和风险提示逐条有来源；认知示意不得进入导航、下载或约伴。
- [ ] 每张图片都有自有、明确授权或合规许可记录，包含作者、来源、许可范围和保存位置；演示图片不能进入发布包。
