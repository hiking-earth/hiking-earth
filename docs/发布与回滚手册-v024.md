# 徒步地球发布与回滚手册 v024

日期：2026-08-24

## 发布前

1. 确认上线前最后一步清单全部勾选。
2. 确认正式域名使用 HTTPS。
3. 检查 NEXT_PUBLIC_SITE_URL 与正式域名一致。
4. 仅在发布闸门全部通过后开启 NEXT_PUBLIC_RELEASE_READY。
5. 执行完整构建与自动测试。
6. 检查 /api/health 返回 status=ok 且 releaseReady=true。
7. 检查 /robots.txt 已由 Disallow 切换为 Allow。

## 发布后五分钟检查

- 首页、地图、路线筛选和路线详情。
- 官方天气可用与不可用两种状态。
- /privacy、/terms、/sources、/release。
- PWA manifest、图标和 Service Worker。
- 安全响应头。
- 1366×768 和 1920×1080 布局。

## 回滚

- 优先重新部署上一个已经验收的不可变版本。
- 本地源码可从 /Users/nanyu/Documents/项目/全球徒步项目/版本留档/ 中对应版本恢复。
- 不删除失败版本和证据；记录失败时间、版本、错误和处理结果。
- 当前无云数据库和对象存储，浏览器本地数据不会随网页版本部署或回滚自动迁移。

## 监控

- 使用 /api/health 做基础存活检查。
- 地图、天气和图片均为外部依赖，应单独监测失败率。
- 开放状态属于人工复核数据，重要公告即时更新，常规状态至少每 12 小时检查一次。
